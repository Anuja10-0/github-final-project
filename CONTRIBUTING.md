# Contributing

Thank you for your interest in contributing to the Simple Interest Calculator project.

## Contributions

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and test them.
4. Commit your changes with a clear and descriptive commit message.
5. Push your branch to your fork.
6. Create a pull request describing your changes.

## Bug Reports

If you find a bug, please create an issue and provide:

* A clear description of the problem.
* Steps to reproduce the issue.
* Expected behavior.
* Actual behavior.
* Any relevant error messages or screenshots.

## Feature Requests

Feature requests and improvement ideas are welcome. Please describe the proposed feature, why it would be useful, and how it could improve the project.

## Documentation

Documentation improvements are also encouraged. Contributions that make the project easier to understand, use, or contribute to are welcome.

## Pull Requests

Before submitting a pull request, please ensure that:

* Your changes are tested.
* Your code is clear and readable.
* Your changes do not introduce unnecessary modifications.
* Your commit messages clearly describe the changes.
* The pull request provides a concise description of the work completed.
