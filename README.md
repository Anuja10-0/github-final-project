# Simple Interest Calculator

A simple Bash-based calculator that computes **Simple Interest** based on the principal amount, rate of interest, and time period provided by the user.

## Project Description

This project demonstrates the use of Git and GitHub for managing a software project. It includes a Bash script that calculates simple interest using user-provided values.

The project was created as part of the **Introduction to Git and GitHub** final project.

## Simple Interest Formula

The calculator uses the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:

* **Principal** is the initial amount.
* **Rate** is the annual rate of interest.
* **Time** is the time period in years.

## Usage

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Navigate to the project directory:

```bash
cd YOUR_REPOSITORY
```

Make the script executable:

```bash
chmod +x simple-interest.sh
```

Run the calculator:

```bash
./simple-interest.sh
```

The script will ask you to enter:

1. Principal amount
2. Rate of interest
3. Time period

It will then calculate and display the simple interest.

## Example

```text
Enter the principal:
10000

Enter the rate of interest:
5

Enter the time period:
2

Simple Interest: 1000
```
